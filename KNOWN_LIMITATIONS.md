# KNOWN_LIMITATIONS

- Python code is not executed for real in V1.
- `MockPythonRunner` returns puzzle-specific mock output.
- Room 0, 2, 3, and 4 use placeholder puzzle content.
- All visuals are CSS placeholders, not final game art.
- There is no audio, animation system, or asset pipeline yet.
- Door code inputs accept the known room code without requiring every puzzle to be solved.
- There is no teacher/admin mode.
- There is no analytics or export of student code drafts.
- Accessibility is basic and should be expanded before classroom deployment.
